# Hamdee investment workspace

This standalone demo belongs to HAMDEE INTERNATIONAL at `/hamdee-crm/index.html`. It uses the supplied original logo unchanged. It does not inherit another venture's theme.

The owner reviews a property's cash, deductions and partner allocation before approving distributions. The working domain is acquisition deposits, capital contributions, rent periods, cheque clearance, vendor warranties and distributable return. The color world is warm limestone, white paper, charcoal ink, muted brass and quiet sage. The signature is a property return bridge alongside a distinct company service-income ledger. Avoid listing photography, generic sales pipelines and a single blended account balance.

Gold #C7A663 is reserved for primary actions, selected navigation and the return bridge. White panels sit on #F7F8FA; company-account panels use charcoal with white text. Property/investor and company accounts carry explicit text labels. Inter, hosted locally, uses a 13px working base, 11px metadata, 16px section titles, 28px headings and 30px financial focal values. Tables use tabular numerals. Sidebar 232px; desktop content padding 28px; card padding 20px; spacing base 4px; radius 10px; quiet #E8E9EC borders with shadows only on overlays. Controls are at least 40px, touch controls 44px. Mobile stacks the content, uses a dismissible navigation sheet and retains independent table scrolling.

## Read-only motion assessment, before implementation

| Location | Purpose | Frequency | Recipe |
| --- | --- | --- | --- |
| Save-feedback toast | Feedback | Occasional | opacity 0 to 1, translateY 8px to 0, 160ms cubic-bezier(0.23,1,0.32,1) |
| Detail drawer | Spatial consistency | Occasional | translateX 16px to 0 and opacity 0 to 1, 200ms cubic-bezier(0.32,0.72,0,1) |

Reject chart drawing (data must stay readable), financial number counting (hinders comparison), route transitions (frequent navigation), and staggered table rows (delays work). Implementation is a separate step after this assessment. Reduced motion disables translation and uses a short opacity change. Modal controls remain interactive throughout. Native dialogs trap focus, Escape closes them and dismissal restores the trigger.

## Financial contract

Each property has independent partner shares, service charge and settlement basis. Investment is capital and does not inflate rental income. Cleared cheques affect received rent once; pending and bounced cheques do not. Carry-forward moves unpaid debt between rent periods without generating cash. Adjustments reduce/increase a due amount and never create receipt income. Expenses carry property/company ownership and operating/capital classification. Service charges are the only cross-layer transfer and are counted once. Settlements snapshot one property and period, require valid shares, prevent duplicate confirmation and track payments separately. Browser-local persistence is explicitly a demonstration, with no live bank or payment operations.
