# Demo font

`inter-latin.woff2` is the unmodified variable Latin Inter font already used by this website, copied from its existing Next.js Google Fonts cache (`e4af272ccee01ff0-s.p.woff2`). It is shared by the two static trading demos to avoid external font requests. Copyright (c) 2016 The Inter Project Authors (https://github.com/rsms/inter).
